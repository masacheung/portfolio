## Gotchas learned
- `npm create astro` in this MSYS shell mangled flags — scaffold manually if re-doing (it worked, just created a `--no-husky` folder that was moved back)
- Astro 5: JSX-style helper `function Card()` inside component frontmatter breaks the build → use separate `.astro` components (done: `ProjectCard.astro`)
- Windows: pass `C:/Users/...` forward-slash paths to native tools; bash `cd` is fine
- `.idea/` was accidentally committed once; it's in `.gitignore` now and was `git rm --cached`
- `write_file` refuses to overwrite a file not read in the current session — `read_file` first
- AGENTS.md in repo suggests `astro dev --background` (Astro 7 feature); on Astro 5 just use terminal background
